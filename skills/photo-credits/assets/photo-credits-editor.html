Photo credit editor

Make sure every picture on your website carries a proper credit. Choose your site folder to list every picture. The editor reads each picture file for the author and copyright stored inside it, shows what is still missing, and saves everything to photo-credits.json, which goes in the top folder of your site. Your pictures stay on this computer.

What counts as complete: a credit, plus the license or permission you are using the picture under. A Creative Commons picture also needs a link to its source page and the license version, and versions 3.0 and earlier need the title. A lead found in a file is evidence, not proof: use it only if you know it is right.

A credit line says who made a picture. It is not permission to use it. If you are not sure you are allowed to use a picture, check with its owner before publishing.
